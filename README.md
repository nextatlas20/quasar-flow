# Quasar Flow

Quasar Flow is the Python SDK for our managed event-routing service.

- `src/quasar/` - first-party SDK modules
- `src/_vendor/` - vendored upstream shims, not part of the public API
- `docs/API_LIFECYCLE.md` - deprecation policy and the published deprecation register

`main` tracks the shipped 2.3.x line; `release/2.4` carries the next minor
release.
